### Git Notes

`git add` moves changes to the staging area, while `git commit` records them in the repository history.

`.env` must not be committed because it may contain sensitive information such as passwords, API keys, and other secrets.

- `git diff` displays unstaged changes.
- `git diff --staged` displays staged changes that will be included in the next commit.
